# 隐私政策

**生效日期：2026-06-19**

鱼头 API（以下简称"我们"）非常重视您的隐私。本隐私政策说明了 鱼头 API（以下简称"本服务"）在您使用 https://yutou.virtualgoods.top 时，如何收集、使用、存储、共享和保护您的信息。

**请您在使用本服务前仔细阅读本政策。当您使用本服务时，即表示您同意本政策所述的信息处理方式。**

## 一、我们收集的信息

### 1.1 您主动提供的信息

- **账户信息**：注册时的用户名、密码（加密存储）、电子邮箱等。
- **第三方登录信息**：若您选择通过 GitHub、Discord、OIDC 等方式登录，我们会获取该平台授权范围内的基础账户标识信息。
- **支付信息**：充值时产生的订单记录、交易流水号等。**我们不存储您的完整银行卡号、支付密码等敏感支付凭证**，相关支付由第三方支付渠道处理。

### 1.2 您使用服务时产生的信息

- **API 调用数据**：调用的模型、请求与响应的 token 用量、调用时间、消耗额度、调用来源标识等计费与统计信息。
- **请求内容**：您通过本服务提交给上游 AI 提供商的请求内容（Prompt）及返回结果。详见第三节"关于请求内容的处理"。
- **日志信息**：IP 地址、浏览器/客户端类型、访问时间、操作记录等用于安全审计与故障排查的技术日志。

### 1.3 自动收集的信息

我们可能使用 Cookie 或类似技术维持登录状态、保存偏好设置及保障账户安全。您可通过浏览器设置管理 Cookie，但禁用后可能影响部分功能的正常使用。

## 二、我们如何使用信息

我们收集的信息用于以下目的：

1. 提供、维护和改进本服务，完成接口调用与转发。
2. 进行额度计费、扣费结算及账单生成。
3. 验证身份、保障账户与平台安全，防范滥用、欺诈及攻击行为。
4. 进行故障排查、性能优化与服务统计分析。
5. 在必要时向您发送服务通知、安全提醒或重要变更告知。
6. 履行法律法规规定的义务，配合有权机关的合法要求。

## 三、关于请求内容的处理（重要）

由于本服务为 **AI 接口聚合与转发平台**，关于您提交的请求内容（Prompt）及返回结果，请您特别注意：

1. **转发至上游提供商**：您的请求内容将被转发至您所选模型对应的**上游 AI 提供商**（如 OpenAI、Anthropic、Google 等）进行处理。**这些内容将受相应上游提供商的隐私政策与数据处理条款约束**，其是否留存、是否用于模型训练等，由上游提供商决定，不在我们的完全控制范围内。
2. **建议您**：在了解并接受上游提供商相关政策的前提下使用本服务；**请勿在请求内容中提交您不希望被第三方处理的高度敏感信息**（如身份证号、银行账户、医疗记录、商业机密等）。
3. **本服务的留存策略**：为保护隐私，本服务**默认不留存**您的请求与响应正文，仅记录用于计费的 token 用量、调用模型、调用时间等元数据。如因排障需要临时开启日志，将在问题解决后及时清除。

## 四、信息的共享与披露

除以下情形外，我们不会向第三方出售、出租或共享您的个人信息：

1. **上游 AI 提供商**：为完成接口调用，将必要的请求内容转发给相应上游提供商（见第三节）。
2. **支付服务商**：为完成充值交易，向第三方支付渠道提供必要的订单信息。
3. **法律要求**：根据适用法律、法规、诉讼程序或政府机关的强制性要求进行披露。
4. **保护权益**：为保护本服务、用户或公众的权利、财产或安全所合理必要的披露。
5. **您的授权**：在获得您明确同意的其他情形。

## 五、信息的存储与保护

1. **存储地点**：您的信息存储于我们使用的服务器及云服务设施中（可能位于中国境内或境外）。如您对数据跨境存储有疑问，可通过文末方式联系我们了解详情。
2. **存储期限**：我们仅在实现本政策所述目的所必需的期间内保留您的信息，法律另有要求的除外。
3. **安全措施**：我们采取合理的技术与管理措施（如密码加密存储、访问控制、传输加密等）保护您的信息安全。但请您理解，**互联网环境并非绝对安全，我们无法保证信息百分之百安全**。

## 六、您的权利

在适用法律允许的范围内，您有权：

1. **访问与更正**：查询、更正您的账户信息。
2. **删除**：在符合条件时，请求删除您的个人信息或注销账户。
3. **撤回同意**：撤回您此前作出的同意（可能影响相关功能的使用）。
4. **投诉**：就个人信息处理向我们或有权监管机构投诉。

如需行使上述权利，请通过 **support@yutou.virtualgoods.top** 与我们联系。我们将在合理期限内核实并响应您的请求。

## 七、第三方服务与链接

本服务可能集成或链接第三方服务（如登录提供商、支付渠道、上游 AI 提供商）。这些第三方有其独立的隐私政策，**本政策不适用于第三方服务**。建议您在使用前阅读相关第三方的隐私政策。

## 八、未成年人保护

本服务主要面向成年人。我们不会主动向未成年人收集个人信息。若您是未成年人，请在监护人同意并指导下使用本服务。如我们发现未经监护人同意收集了未成年人信息，将尽快删除。

## 九、本政策的变更

我们可能适时更新本隐私政策。更新后的政策将通过 https://yutou.virtualgoods.top 公布并注明生效日期。**重大变更我们将以适当方式提示。您在政策更新后继续使用本服务，即视为接受修订后的政策。**

## 十、联系我们

如您对本隐私政策或个人信息处理有任何疑问、意见或投诉，请通过以下方式联系我们：

- **运营主体**：鱼头 API
- **联系邮箱**：support@yutou.virtualgoods.top
- **网站**：https://yutou.virtualgoods.top
