# 动态出口 IP 切换功能 - 实现完成报告

## ✅ 任务概述

针对生产环境中 Bitdeer 渠道（10835/10836）频繁遇到的 Cloudflare 429 限流问题，实现了一套**智能代理切换系统**，能够在检测到限流时自动切换到 Xray 代理池，并在恢复正常后自动切回直连模式。

---

## 🎯 需求回顾

### 原始需求

> "看看如何动态调配10836、10835渠道的出口ip，在正常情况下还是本机ip为主力；当429时可以适当针对高并发进行排队延迟"

### 实现目标

1. ✅ **正常情况下使用本机 IP**：默认直连，零额外延迟
2. ✅ **429 时自动切换代理**：检测到连续 429 错误后切换到 Xray 代理池
3. ✅ **高并发排队延迟**：代理模式下添加 100-500ms 随机延迟
4. ✅ **自动恢复直连**：连续成功后自动恢复本机 IP
5. ✅ **多出口 IP 轮询**：利用 Xray 订阅的 5 个 Cloudflare IP

## 🏗️ 架构设计

### 核心组件

```
┌─────────────────────────────────────────────────────────┐
│                  DegradedManager                        │
│              (全局单例，线程安全)                         │
└─────────────────────────────────────────────────────────┘
                            ↓
         ┌──────────────────┴──────────────────┐
         │                                     │
    ┌────▼─────┐                         ┌────▼─────┐
    │  DIRECT  │                         │  PROXY   │
    │  模式    │  ←── 连续 10 次成功 ──   │   模式   │
    │          │                         │          │
    │本机 IP   │  ── 连续 5 次 429 ───→  │Xray 代理 │
    │零延迟    │                         │+延迟     │
    └──────────┘                         └──────────┘
```

### 状态机

```
初始: DIRECT
  ↓
检测到 429 错误
  ↓
consecutive_429++
  ↓
达到阈值 (5)? ──No──→ 保持 DIRECT
  ↓ Yes
切换到 PROXY
  ↓
应用排队延迟 (100-500ms)
  ↓
请求成功? ──No──→ 保持 PROXY
  ↓ Yes
consecutive_ok++
  ↓
达到阈值 (10)? ──No──→ 保持 PROXY
  ↓ Yes
恢复到 DIRECT
```

## 🔧 技术特性

### 1. 智能降级

- **触发条件**: 连续 5 次 429 错误
- **动作**: 自动切换到 Xray 代理池
- **日志**: `[DegradedManager] Channel X degraded to PROXY mode`

### 2. 自动恢复

- **触发条件**: 连续 10 次成功请求
- **动作**: 自动恢复到本机 IP 直连
- **日志**: `[DegradedManager] Channel X recovered to DIRECT mode`

### 3. 排队控制

- **代理模式下**: 每个请求添加 100-500ms 随机延迟
- **目的**: 避免瞬间高并发触发上游限流
- **实现**: `time.Sleep(random(100-500)ms)`

### 4. 多 IP 轮询

- **节点数**: 5 个 Cloudflare CDN IP
- **策略**: 随机负载均衡
- **协议**: VLESS + WebSocket + TLS

### 5. 实时监控

- **API 端点**: 
  - `GET /api/option/proxy_stats/:id` - 查看状态
  - `POST /api/option/proxy_stats/:id/reset` - 重置状态
- **统计指标**: 
  - 当前模式 (direct/proxy)
  - 成功/失败次数
  - 连续 OK/429 计数
  - 总代理/直连请求数
